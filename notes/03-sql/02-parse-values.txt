Parse Values
В настоящее время реализованы только 2 типа данных: int64 и string. Они различаются по
первому символу:
```rust
impl<'a> Parser<'a> {
    pub fn parse_value(&mut self) -> Result<CellType, ParseError> {...}
}
```
Логика:
```
'  -> string
"  -> string
digit/+/- -> int
else error
```
Когда позже будет реализован синтаксический анализ, станет видно, что многие языки могут определять, как выполнять дальнейший анализ, на основе первых нескольких токенов
---
Разбор int64
Правила для int64 просты: он может начинаться с - или +, за которыми следуют цифры.
```go
impl<'a> Parser<'a> {
    fn parse_int(&mut self) -> Result<CellType, ParseError> {...}}
```
---
Разбор строк
```go
impl<'a> Parser<'a> {
    fn parse_string(&mut self) -> Result<CellType, ParseError> {..}}
```
Правила :
- заключены в одинарные или двойные кавычки
- кавычки внутри строки должны быть экранированы косой чертой
- косая черта также должна быть экранирована косой чертой
Например, "is\'nt" или "is\'nt" оба означают "is't".
* Для практического применения необходимы дополнительные экранирующие символы, такие как \n, \xFF, \u3412, но это пока не делаем
'...',"...",\', \", \\
